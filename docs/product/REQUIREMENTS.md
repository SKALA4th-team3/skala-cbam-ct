# 요구사항 명세

> **출처** — 팀 작성 「찐찐막 요구사항 명세」. 이 문서는 그 표를 저장소 안으로 옮긴 것이다.
> 원본과 이 문서가 다르면 **원본이 맞다.** 발견하면 이 문서를 고치고 팀에 알린다.

**기능 53개 · 대상 3종 · 분류 13종.**

| 대상 | 개수 |
| --- | --- |
| 원청 (사람이 하는 일) | 37 |
| 시스템(AI) | 12 |
| 시스템(메일) | 4 |

## 번호 규칙

원본 표의 **번호 열을 그대로 쓴다.** `1` ~ `53`. **접두어를 붙이지 않는다 — 원본에 없다.**

```
1 ~ 53        기능 번호 (원본 표의 「번호」 열)
UC-04 ~ UC-10 유스케이스 (원본 「UC」 열에서 참조)
R1 ~ R7       위험 탐지 규칙 (원본 42번 「비고」에 심각도만)
```

**이 번호가 저장소의 공용어다.** Jira 이슈·브랜치·커밋·PR이 전부 이것을 가리킨다.

글·커밋·PR·Jira 제목에는 **「24번」**, 브랜치명에는 **`24-`** 를 쓴다 (브랜치는 소문자 케밥케이스라 한글을 못 쓴다).

---

## ⚠️ 우선순위와 담당자는 이 문서에 없다

원본 표의 **우선순위·담당자(B/F) 두 열은 53개 전부 비어 있다.** 이 문서는 그 두 열을 **채우지 않는다.**

| 무엇 | 기준 |
| --- | --- |
| **무엇을 만드는가** | **이 문서** — 1 ~ 53번 |
| **어느 것을 먼저, 누가** | **Jira 보드** |

**우선순위와 담당은 하루에도 몇 번 바뀐다.** 그것을 이 표에 적으면 5명이 **같은 파일의 같은 줄**을 동시에 고치게 되고, 3일 중 하루를 충돌 해결에 쓴다.

**보드는 움직이는 기준이고, 이 문서는 움직이지 않는 기준이다.** 둘을 섞지 않는다.

**3일에 기능 53개는 다 못 만든다.** 첫 회의에서 **보드의 우선순위부터** 정한다. 정하지 않으면 각자 만들고 싶은 것을 만들게 되고, 3일차에 **화면은 많은데 하나도 안 이어지는 상태**가 된다.

무엇이 먼저인지는 [`AGENTS.md`](../../AGENTS.md)의 **「최소한 이 줄 하나는 끝까지 이어져야 한다」** 를 본다.

## 아직 정해지지 않은 것

**아래는 원본에 미결정으로 남아 있다. 임의로 확정하지 않는다.** 정해야 할 때가 오면 팀에 묻고, 정해지면 [`docs/decisions/`](../decisions/README.md)에 남긴다.

| 어디 | 원본 표기 |
| --- | --- |
| 4번 | 「정렬 : 고민해보기」 — 협력업체 목록 정렬 기준 |
| 34번 | 「IQR?」 — 이상치 판정을 ±30% 고정으로 할지 IQR로 할지 |
| 38번 | 「정렬/필터 알잘딱」 — 대시보드 정렬·필터 기준 |
| 43번 | 「AI 프롬프트로 생성 예정」 — 일괄 초안 프롬프트 미작성 |
| R1~R7 | **심각도만 정해져 있고 규칙 내용이 없다** |
| UC 문서 | UC-04~UC-10이 참조되는데 **UC 문서 자체가 없다** |

**UC 문서가 없는 것이 가장 크다.** 명세가 6곳에서 UC를 가리키는데 가리킬 문서가 없다. 만들거나, 안 만들 거면 UC 열을 지운다 — 둘 중 하나를 정한다.

| **3** | 리스트 조회 | 페이지 단위 조회. 업체명 검색과 국가·상태(협력유지중/협력끊김) 필터. 업체별 **월별 제출 상태(최근 12개월)** 표시. |

| --- | --- | --- |

| **24** | 단위/형식 표준화 | 표준 단위(tCO2e, ton)로 변환. **변환 전 원본 값을 함께 보존하고, 변환할 수 없는 값은 비워 둔 채 사유를 남긴다.** |

## 이 명세를 관통하는 규칙

**모르면 비우고 사유를 남긴다.** 다섯 곳이 같은 말을 한다.

| | 원문 |
| --- | --- |
| 19번 | 「일치하는 업체가 없으면 **미확인** 상태로 두고 담당자에게 알린다」 |
| 20번 | 「첨부가 없거나 지원하지 않는 형식이면 **접수 불가**로 기록한다」 |
| 22번 | 「암호가 걸렸거나 파싱에 실패하면 **분석 실패**로 기록한다」 |
| 24번 | 「변환할 수 없는 값은 **비워 둔 채 사유를 남긴다**」 |
| 25번 | 「일치하는 부품이 없으면 **미등록 부품**으로 표시한다」 |

**이것이 이 제품의 핵심이다.** 규제 신고에 쓰이는 데이터라, 그럴듯하게 채운 값은 틀린 값보다 나쁘다 — 아무도 그것이 추정인지 모르기 때문이다.

**30번이 그 증거다** — 「표준화 값과 원본 값을 나란히」 보여준다. 원본을 지웠으면 이 화면을 만들 수 없다.
